# Site do ASMUBE Design System

Documentação interativa (Vite + React + Tailwind v4 + shadcn/ui) publicada no GitHub Pages.

- Rode a partir da raiz: `npm run site:dev` (gera os tokens e abre o site) ou `npm run site:build`.
- `src/tokens.json` e `src/asmube-tokens.css` são gerados por `npm run build` na raiz — não edite à mão.
- Tema shadcn → ASMUBE em `src/index.css`.
