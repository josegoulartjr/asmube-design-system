Cores

Paleta

As escalas são geradas em OKLCH a partir das duas cores oficiais (marcadas com ●). Todas mantêm o mesmo matiz da cor base; só mudam luminosidade e saturação.

Cores de uso (semânticas)

Use sempre estas nos layouts, não as escalas diretamente. Se a marca mudar, só o mapeamento muda.

Contraste

Regra de ouro do verde

Nunca use texto branco sobre o verde #6AA842 (2,88:1). Sobre o verde, o texto é sempre azul profundo (texto.sobre-destaque). Verde sobre azul só em títulos grandes, ícones e grafismos.

Tipografia

Montserrat em duas escalas

Web (site, landing pages, e-mail): base 16px, razão 1,25 (Terça Maior), entrelinha na grade de 4px. Peças (posts, slides, impressos): razão 1,333 (Quarta Justa), com base diferente por formato.
